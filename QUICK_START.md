# Quick Start / Быстрый старт

Windows only.

## RU
1. Открой страницу релиза: https://github.com/ruslantitov/emoji-machine-gun-zoom/releases/latest
2. Скачай файл `emoji-machine-gun-zoom-v1.0.x.zip`
3. Распакуй ZIP
4. Открой папку с файлами
5. Дважды нажми файл `START.cmd` в корне папки
6. Если Windows скрывает расширения, файл может выглядеть просто как `START`
7. Программа будет висеть в трее и ждать Zoom
8. Когда Zoom закроется, программа тоже закроется
9. На первом запуске программа сама сохранит себя в папку Zoom и включит автозапуск
10. Открой Zoom и пользуйся:
   - `F5` - `heart -> thumbs up -> clap`
   - `F6` - `clap`
   - `F7` - `thumbs up`
   - `F8` - `heart`
   - `F9` - `tada / party`

## EN
1. Open the release page: https://github.com/ruslantitov/emoji-machine-gun-zoom/releases/latest
2. Download `emoji-machine-gun-zoom-v1.0.x.zip`
3. Unzip the archive
4. Open the extracted folder
5. Double-click `START.cmd` in the root of the folder
6. If Windows hides file extensions, it may appear as just `START`
7. The program will stay in the tray and wait for Zoom
8. When Zoom closes, the program closes too
9. On first run, the program copies itself into the Zoom folder and enables startup
10. Open Zoom and use the hotkeys:
   - `F5` - `heart -> thumbs up -> clap`
   - `F6` - `clap`
   - `F7` - `thumbs up`
   - `F8` - `heart`
   - `F9` - `tada / party`
